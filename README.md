# Telegram-бот для новых объявлений Kufar

## Что умеет
- принимает ссылку на поиск Kufar.by с выбранными фильтрами;
- сохраняет несколько поисков для каждого пользователя;
- запоминает уже видимые объявления и уведомляет о новых;
- `/list` — список поисков;
- `/delete НОМЕР` — удалить поиск;
- проверяет примерно раз в 120 секунд (минимум 60 секунд).

## Установка на компьютере

Нужен Python 3.11 или новее.

1. Создай бота через `@BotFather` в Telegram и скопируй токен.
2. Распакуй архив в папку.
3. В этой папке создай файл `.env` — скопируй туда содержимое `.env.example` и вставь токен.
4. Открой терминал в папке проекта и выполни:

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

macOS/Linux:
```bash
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

5. Открой своего бота в Telegram и отправь `/start`.
6. На Kufar настрой поиск (категория, город, цена и другие фильтры), скопируй URL страницы результатов и отправь боту.

## Важно
- Компьютер должен быть включён, а программа — запущена, иначе проверок и уведомлений не будет.
- Парсер читает публичную страницу и может потребовать адаптации, если Kufar поменяет разметку или ограничит автоматические запросы.
- Не используй частые запросы, не обходи CAPTCHA/ограничения и проверь правила Kufar перед постоянным автоматизированным использованием.
- Не добавляй в `.env` файл токен в публичные репозитории и никому его не отправляй.
